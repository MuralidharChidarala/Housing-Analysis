# Housing Market Analysis Dashboard

## 📌 Project Overview

The **Housing.pbix** file is a comprehensive Power BI dashboard project built to analyze housing market data, monitor sales performance, and understand property trends through interactive visualizations. This report transforms raw housing data into meaningful business insights that can support decision-making for real estate agencies, investors, analysts, and management teams.

The dashboard is designed with a clean layout, intuitive navigation, and dynamic filters that allow users to explore data from multiple perspectives such as price trends, sales growth, house types, regional demand, and performance over time.

## 📂 Repository Contents

* **Housing.pbix** – Main Power BI report file.

## 🎯 Project Objectives

This dashboard was created to:

* Analyze overall housing market performance.
* Track sales revenue and transaction trends.
* Compare property categories and house types.
* Identify high-performing regions or locations.
* Visualize demand and pricing patterns.
* Support business decisions using data insights.

## 📊 Dashboard Pages Included

### 1. House Market Overview

This page provides a summary of the complete housing market using high-level KPIs and visuals.

**Includes:**

* Total Properties Listed
* Total Sales Value
* Average Property Price
* Number of Transactions
* Monthly / Yearly Growth Trends
* Regional Market Comparison

### 2. Sales Performance

Focused on revenue and transaction analysis.

**Includes:**

* Sales by Month / Quarter / Year
* Revenue Growth Trends
* Top Performing Areas
* Average Selling Price
* Sales Distribution Charts
* Performance Comparison Metrics

### 3. House Type Analysis

Provides insights into different categories of properties.

**Includes:**

* Apartments vs Villas vs Independent Houses
* Price Comparison by Type
* Sales Count by Property Type
* Demand Trends
* Profitability / Revenue Contribution
